# 코치 시범 영상으로 방어 동작 맞추기

BoxingVI에는 방어 동작(슬립·더킹·위빙·스웨이)이 없다. 그래서 유튜브 코치 시범 영상에서 MediaPipe로 3D 포즈를 뽑아
`lib/pose/poses.dart`의 방어 자세를 맞췄다. 영상과 포즈 데이터는 저장소에 넣지 않고, 수치를 맞추는 기준으로만 쓴다.

## 쓴 영상

| 영상 | 내용 | 쓴 구간 |
|---|---|---|
| [Coach Pillow Fists – Slip, Roll, Pull, Duck](https://www.youtube.com/watch?v=zvI2qR6cTq4) | 한 사람, 전신, 오소독스 | 슬립 95–111초, 더킹·롤 111–153초, 스웨이 153–185초 |
| [FightCamp – How To Slip Punches](https://www.youtube.com/watch?v=-cfSa-gBxtc) | 전신 정면, 오소독스 | 정지 슬립 5개 (슬립 방향·회전 교차 확인) |

## 다시 돌리기

```bash
python -m venv .venv && .venv/Scripts/pip install yt-dlp mediapipe opencv-python numpy matplotlib imageio-ffmpeg
# 1. 영상 받기 (프로젝트 밖 별도 폴더에)
.venv/Scripts/yt-dlp -f "bv*[height<=720][ext=mp4]+ba[ext=m4a]" --merge-output-format mp4 -o "<영상 폴더>/%(id)s.%(ext)s" zvI2qR6cTq4 -- -cfSa-gBxtc
# 2. 포즈 추출 (모델: https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_heavy/float16/latest/pose_landmarker_heavy.task)
.venv/Scripts/python -I tool/video_pose/extract.py pose_landmarker_heavy.task <영상 폴더>/zvI2qR6cTq4.mp4 <작업 폴더>/z.npz
# 3. 구간 확인 → 동작별 측정
.venv/Scripts/python -I tool/video_pose/plot.py <작업 폴더>/z.npz plot.png 55 200      # 시계열 그래프
.venv/Scripts/python -I tool/video_pose/frames.py <영상> frames.png 62,77,114.3,163    # 해당 시각 프레임
.venv/Scripts/python -I tool/video_pose/defense.py <작업 폴더>/z.npz slip 95 111       # slip / duck / pull
```

## 방법

- MediaPipe 3D 좌표는 똑바로 선 자세에서도 12~16° 숙인 것으로 나올 만큼 깊이 오차가 있다.
  그래서 절댓값은 쓰지 않고, 각 동작 앞뒤 가드 자세 대비 **변화량**만 쓴다.
- 길이는 몸통 길이(어깨 중앙~골반 중앙) 단위다. 인형의 몸통 길이는 0.52.
- 낮춤 정도는 2D 화면 좌표로도 다시 쟀다. 엉덩이~발목 세로 길이를 똑바로 선 자세와 비교했다.

## 결과 (가드 대비 변화, 중앙값)

| 동작 | 실제 | 조정 전 인형 | 지금 인형 |
|---|---|---|---|
| 슬립 기울기 | 23~25° | 33° | 24~25° |
| 슬립 어깨 회전 | 리드 쪽 −27°(FightCamp −46~−62°), 리어 쪽 +25°(+66°) | 리드 쪽 +10°, 리어 쪽 −15° (**반대 방향**) | −30°, +30° |
| 슬립 시간(가드→정점) | 0.30~0.35초 | 0.36초 | 0.36초 |
| 더킹 낮춤 | 엉덩이 높이가 선 자세의 74~78% (인형 단위 0.15) | 0.32 | 0.15 |
| 더킹 숙임 | 35° | 28° | 35° |
| 롤 바닥 | 0.14 낮춤, 34° 숙임, 옆으로 23°, 어깨 35° 회전 | 0.32 낮춤, 25° 숙임 | 0.16 낮춤, 33° 숙임, 끝에서 22°·30° 회전 |
| 스웨이 젖힘 | 14~30° (높이 그대로) | 28° | 20° |

슬립 회전 방향: 리드 쪽으로 슬립하면 뒷어깨가 앞으로 나와 크로스를 친 것 같은 자세가 된다.
리어 쪽으로 슬립하면 앞어깨가 앞으로 나온다. 두 코치 모두 같았다.
앱의 체중 규칙(리드 쪽 슬립 뒤엔 리드 훅이 자연스러움)과도 맞는 방향이다.

## 바디 스트레이트 (`bodyshot2d.py`)

| 영상 | 쓴 장면 |
|---|---|
| [Coach Pillow Fists – How to Jab to the Body](https://www.youtube.com/watch?v=N4fRupFSnRU) | 옆에 가까운 카메라의 바디 잽 5개 (27~40초) |
| [Tony Jeffries – Cross to the Body](https://www.youtube.com/watch?v=-zywYc6XzO4) | 바디 크로스 4개 (192~193초, 카메라 2대) |

비스듬히 뻗은 팔은 2D에서 짧아 보여 자동 검출이 틀리므로, 임팩트 시각은 프레임을 보고 직접 넣었다.
깊이 오차가 커서 3D 대신 2D 화면 좌표로 쟀다. 가로 거리(보폭)는 비스듬한 시점 때문에 실제보다 짧게 나온다.

| | 바디 잽 실제 | 바디 크로스 실제 | 조정 전 인형 | 지금 인형 (잽 / 크로스) |
|---|---|---|---|---|
| 팔 각도 (수평 아래) | 7~16° | 헤드 펀치와 비슷 (같은 카메라에서 21° 대 19°) | 33~34° | 10° / 11° |
| 엉덩이 낮춤 (몸통 길이 배) | 0.34~0.44 | 0.19~0.33 | 0.38 (보폭은 좁고 두 무릎 다 꺾임) | 0.38 / 0.36 |
| 상체 숙임 증가 | 5~18° | 26° (옆 카메라) | 8° / 10° | 12° / 25° |
| 보폭 증가 (몸통 길이 배) | 0.45~0.77 이상 | 0.44~0.67 이상 | 0.35 / 0.25 | 0.78 / 0.78 |
| 무릎 | 앞무릎 굽히고 뒷다리 거의 폄 | 런지, 뒤꿈치 듦 | 앞·뒤 모두 약 95° | 앞 94~105°, 뒤 152~155° |

실제 바디샷은 팔을 아래로 꺾지 않는다. 앞발을 깊게 내딛고 앞무릎을 굽혀 몸 전체를 낮춘 뒤 팔은 거의 수평으로 뻗는다.
골반은 앞발 쪽으로 쏠려서 뒷다리는 펴진다.

## 리드 바디 훅

[Tony Jeffries – Hook To The Body](https://www.youtube.com/watch?v=uXsOssBwLoA) 170~232초에서 포즈를 뽑았다. 어깨 회전 봉우리 22개 기준으로 재면 어깨 51°, 골반 43°가 함께 돈다(중앙값). 헤드 훅이 섞여 있고, 3D 숙임·높이는 노이즈가 커서 쓰지 않았다.
높이와 발 동작은 코치 설명과 프레임을 근거로 했다. 앞으로 숙여 앞발에 체중을 싣고, 앞발은 고정하고, 뒤꿈치를 들어 돌린다. 골반은 정면과 나란해진다.

| | 조정 전 | 지금 |
|---|---|---|
| 어깨·골반 회전 (가드 대비) | +35° / +27° | +45° / +42° |
| 앞발 돌림 | 30° | 5° (고정) |
| 뒷발 | 그대로 | 20° 돌리고 뒤꿈치 듦 |
| 숙임 / 체중 | 0° / 가운데 | 15° 앞으로, 앞발 쪽 |

무릎은 발끝 방향을 따르게 바꿨다. 골반이 크게 돌 때 다리가 X자로 모이던 문제가 없어졌다.

| 허벅지 (몸통 길이 배) | 0.78~0.88 | 0.92 | 0.83 |
| 어깨너비 (몸통 길이 배) | 0.57~0.67 | 0.73 | 0.65 |

다리가 18% 길어서 장대 위에 선 것처럼 보였다.

## 슬립 방향과 카메라

슬립 때 머리는 거의 옆으로만 움직인다 (가드 대비 옆 0.66~0.72, 앞뒤 −0.15~0 몸통 길이).
인형도 머리가 옆 0.6, 앞뒤 −0.06~+0.12가 되게 골반을 같은 쪽 무릎 위로 더 옮겼다.
예전 기본 시점은 상대 방향에서 50° 옆이라 옆 이동의 77%가 화면 깊이로 보여, 슬립이 뒤로 빠지는 것처럼 보였다. 지금은 30°.

## 머리 움직임 (`head.py`)

몸통이 숙이고, 기울고, 돌 때 머리가 얼마나 따라가는지 재서 회귀 기울기로 냈다(1 = 몸통에 붙어 그대로, 0 = 고정).
머리 방향은 귀선과 귀 중앙→코로 정했다. 펀치는 [Oliver Betts – Punches 1-6](https://www.youtube.com/watch?v=JhkqSCahsNY) 40~800초를 썼다.

| 몸통 움직임 | 슬립 | 더킹·롤 | 스웨이 | 펀치 |
|---|---|---|---|---|
| 앞 숙임 | 0.43 | 0.12 | 0.37 | 0.12 |
| 옆 기울기 (몸통 기준) | 0.40 | 0.10 | 0.36 | 0.01 |
| 회전 | (1.3~1.7, 어깨 깊이 오차로 과대) | | | 0.75 |

몸을 숙이거나 기울여도 머리는 세워 두고 시선을 앞에 둔다. 인형은 전부 1이었다.
지금은 옆 기울기 0.3, 앞 숙임 0.25, 회전 0.75로 따라간다.

## 한계

- 코치 두 명의 시범이다. 실전 스파링 동작이 아니다.
- 섀도복싱 영상([Tony Jeffries](https://www.youtube.com/watch?v=J4j3AOVWuHE))으로 가드 바운스도 재 보려 했다.
  말하면서 보여주는 튜토리얼이라 주기·크기가 일정하지 않아 반영하지 않았다. 가드 바운스는 모션캡처로 쟀다 (`tool/mocap`).
- 튜토리얼 시범은 실제보다 느리다. 같은 영상들의 펀치(20%→최대)가 200~300ms로, 모션캡처 펀치(83~108ms)의 2배가 넘는다.
  그래서 방어 동작 시간은 이 영상들에서 잰 값의 0.6배를 쓴다.
- 바디 훅은 회전만 수치로 쟀고, 높이·숙임은 코치 설명과 프레임을 근거로 했다.
